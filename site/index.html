Your agent uses it without seeing it.

#self-host

Run your own relay.

The relay is 133 lines of Convex, plus the page it serves. Pick a theme and a color when you deploy, or write your own theme in plain CSS.

ENCLAVE_THEME
ledger, field, or a path to your own CSS file
ENCLAVE_COLOR
any hex color. Text on it turns white or ink, whichever reads better.

#limits

What it can’t protect against.

  • Whoever runs the relay sends you the page, so they could change it. Every site that encrypts in your browser works this way. If you’d rather trust nobody’s relay, run your own.
  • Anyone with the link can answer first. They can’t read anything, but they could send a fake answer. You’d see “This link doesn’t work anymore.”
  • A link can claim anyone is asking. Only send secrets to agents you asked for help.
  • An agent set on reading its own vault can. enclave stops secrets from leaking into the chat by accident, not a model that’s trying.
